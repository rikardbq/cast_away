# Cast Away
![based](./cast_away.png)
### Something for casting media to Chromecast, that doesn't bug out all the time
- The intention of this application is to be able to cast media with subtitles (VTT) to Chromecast without using Googles Web-Sender-SDK since it relies on having a Chrome browser, AFAIK at least.
- This app is currently a replica of sorts of another rust desktop app project i'm working on called **[homey](https://github.com/rikardbq/homey)**
- This serves as a standalone app but may make its way into **homey** later on
