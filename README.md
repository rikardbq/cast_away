# Cast Away
![based](./cast_away.png)
### Something for casting media to Chromecast, that doesn't bug out all the time
- Rust WRY GUI application with React / Vite frontend
- Currently very messy code but works well enough to discover and cast to devices.
- Future change will be testing CEF(Chrome Embedded Framework) to enable Chrome-Web-Sender-SDK implementation
    - this SDK requires Chrome as far as I'm aware, hence the CEF implementation.
